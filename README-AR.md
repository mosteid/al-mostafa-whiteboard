# منصة الأستاذ مصطفى عيد الصافي — النسخة 3.0

## الملفات
- `src/index.html` — المنصة كاملة (نفس ملف `منصة_المصطفى_3_0.html`).
- `src-tauri/` — مشروع تطبيق ويندوز حقيقي (Tauri 2، خفيف: عادةً 5–10 MB).
- `scripts/vendor.mjs` — ينسخ pdf.js والخطوط والأيقونات محليًا ليعمل التطبيق بدون إنترنت.
- `src/manifest.webmanifest` + `src/sw.js` — بديل أخف: تثبيت المنصة كتطبيق (PWA) من Edge/Chrome.

## بناء تطبيق ويندوز (.exe) — مرة واحدة
المتطلبات: Node.js 18+ و Rust (rustup) و Visual Studio Build Tools (C++).
```
cd desktop-app
npm install
npm run build        # ينفّذ vendor ثم tauri build
```
المثبّت يظهر في `src-tauri/target/release/bundle/nsis/`.
بعد التثبيت: كليك يمين على أي PDF ← **Open with / فتح باستخدام** ← «منصة الأستاذ مصطفى عيد».
(لجعله الافتراضي: Open with ← اختيار تطبيق آخر ← «استخدم هذا التطبيق دائمًا».)
لتجربة سريعة بدون بناء: `npm run vendor` ثم `npm run dev`.

## بديل بدون Rust: PWA
استضف مجلد `src/` على رابط https (أو `localhost`) ← افتحه في Edge ← ⋯ ← التطبيقات ← تثبيت.
التطبيق المثبّت يدعم Open with لملفات PDF ويعمل بدون إنترنت بعد أول زيارة.

## تحويل خط اليد إلى نص
- الزر **✍️→Aa تحويل الخط** في شريط الأدوات. ⚙ لضبط السرعة والخط.
- الترتيب: محرك محلي تضيفه أنت `window.HWR_ENGINE = async (strokes, opts) => "النص"` ← Chrome المحلي (إن وُجد) ← Google عبر الإنترنت.
- بدون إنترنت وبدون محرك محلي: تبقى الكتابة بخط اليد ولا يُفقد شيء.

## ملاحظات
- لتعطيل خاصية التأخير المنخفض للقلم إن ظهر وميض على جهاز معيّن: `localStorage.mb_desync='0'` ثم أعد التحميل.
- كل الحفظ في IndexedDB داخل التطبيق؛ «مكتبتي» تحتفظ بالكتب وكتابتك عليها.
